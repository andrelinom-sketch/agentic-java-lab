# Agentic Java Lab — Setup do Ambiente

Este documento descreve o ambiente necessário para reproduzir o laboratório.

## Sistema de referência

- Ubuntu 24.04 LTS
- Arquitetura: amd64

Outras distribuições Linux podem funcionar, mas os comandos de instalação podem ser diferentes.

## Requisitos

| Ferramenta | Versão requerida | Ambiente de referência |
|---|---|---|
| Git | 2.x+ | 2.43.0 |
| Java | 21 LTS | OpenJDK 21.0.12 |
| Maven | 3.8+ | 3.8.7 |
| Docker Engine | 29.x | 29.8.1 |
| Docker Compose | Compose v2+ | 5.5.1 |
| Node.js | 22 LTS | 22.23.2 |
| npm | compatível com Node 22 | 10.9.8 |
| NVM | recomendado | 0.40.7 |
| BMAD Method | 6.x | 6.12.0 |
