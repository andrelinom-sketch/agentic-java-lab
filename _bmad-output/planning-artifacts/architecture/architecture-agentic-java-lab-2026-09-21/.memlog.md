- (question) Pendencias do PRD a decidir aqui: concorrencia, IDs, precisao monetaria, valores de status, HTTP, mecanismo do Marco de congelamento e da protecao da baseline, conteudo do CI/testes de referencia, escopo de implementacao da V1
- (direction) Usuario: sem pesquisa web de versoes agora; stack (Java 21, Spring Boot, PostgreSQL, Maven, JUnit, Testcontainers) ja definida; versoes estaveis compativeis escolhidas na criacao do projeto; sem ADRs agora; modo rapido, sem novas rodadas de alternativas
- (decision) AD-1 [ADOPTED] monolito de um modulo Maven, pacote por funcionalidade (account, transfer); web/service/repository/model sao organizacao inicial, sem obrigacao de criar camadas/classes desnecessarias; codigo/API em ingles; ArchUnit protege so fronteiras relevantes, sem regras artificiais
- (decision) AD-2 [ADOPTED] account e o unico dono do saldo e de sua mutacao; transfer so acessa account pelo servico publico de account (nunca repository/model); web nao acessa repository
- (decision) AD-3 [ADOPTED] Spring Data JPA + PostgreSQL; esquema so por migracoes Flyway; @Transactional no servico; uma transferencia = uma transacao atomica (debito, credito, registro)
- (decision) AD-4 [ADOPTED] concorrencia: SELECT FOR UPDATE nas duas contas em ordem crescente de id, saldo verificado apos o lock, CHECK (balance >= 0) no banco, isolamento padrao do PostgreSQL; alternativas descartadas: otimista com retry, SERIALIZABLE
- (decision) AD-5 [ADOPTED] dinheiro: BigDecimal/NUMERIC(19,2), BRL implicita sem campo de moeda, rejeitar mais de 2 casas decimais sem arredondar, numero decimal no JSON; alternativa descartada: centavos em long
- (decision) AD-6 [ADOPTED] ids UUID v4 gerados pela aplicacao; status de Transferencia com um unico valor COMPLETED (texto); novos estados so por migracao com necessidade real e aprovacao humana; alternativas descartadas: BIGSERIAL, PENDING/COMPLETED/FAILED
- (decision) AD-7 [ADOPTED] contrato HTTP: POST /accounts 201+Location; GET /accounts/{id} 200/404; POST /transfers 201+Location; GET /transfers/{id} 200/404; erros 400 entrada invalida, 422 regra de negocio; Problem Details RFC 9457 com codigo estavel; sem prefixo de versao e sem autenticacao
- (decision) AD-8 [ADOPTED] testes: JUnit 5 + PostgreSQL real via Testcontainers, conteiner compartilhado por execucao; HTTP contra o banco como principal; unitarios so para logica pura; um teste de concorrencia; ArchUnit; sem H2; testes de referencia em pacote separado (reference) identificaveis dos testes do agente
- (decision) AD-9 [ADOPTED] CI minimo: GitHub Actions em PR e push na main; JDK 21; cache Maven; mvn verify (compilacao estrita, testes, ArchUnit); JaCoCo so informativo; analise estatica adiada ate necessidade concreta (rubrica: quando existir)
- (decision) AD-10 [ADOPTED simplificado] Marco de congelamento = tag Git anotada freeze/exp-NN na main; branch do experimento nasce da tag; docs/lab/baseline.md lista os artefatos congelados; testes de referencia separados; mudanca da baseline durante o experimento exige aprovacao humana e registro como mudanca/desvio; CODEOWNERS e job de guarda NAO implementados na V1, avaliar apos o primeiro experimento
